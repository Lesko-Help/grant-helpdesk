# Review

## Files that always get a full human read
One line per file or path where a diff is never skimmed — because a
mistake there is expensive or silent.

## review:N threshold
One line: the diff-line count above which a change gets the full agentic
review, below which it does not.

## Verdict log
One line per landed change — date, branch, verdict — appended to, never
rewritten.
